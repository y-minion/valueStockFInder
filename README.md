# valueStockFInder

배당주 분석 계산기(엑셀)의 네 관문을 국내 상장 주식 전체에 자동으로 적용하는 주간 스크리너예요.

- **관문 ①②③을 계산해요.** 좋은 회사인가, 배당이 오래 갈까, 지금 싼가.
- **매수선에 가까운 종목을 리포트로 보여줘요.**
- **관문 ④(싼 이유가 일시적인가)는 사람이 판단해요.** 판단 재료(공시·뉴스·분기 실적)를 모아 주고, `/자문`으로 AI와 같이 볼 수 있어요.

리포트의 숫자는 공식 API와 엑셀 수식만으로 만들어요. 실행 중에 AI는 쓰지 않아요. 같은 입력이면 매번 같은 결과가 나오고, 엑셀 계산기와 판정이 같아요.

**점수 순위 (2026-11-23 추가):** 최근 해에 배당을 준 종목(금융 포함)마다 100점 점수를 매겨 첫 화면에 순서대로 보여줌. 관문을 다 통과하지 못해도 살 근거가 많은 종목을 찾는 용도. 이익 지속성·성장 잠재력·경영·브랜드는 점수에 넣지 않고 카드와 `/자문`에서 꼭 같이 봄.

## 준비 (처음 한 번)

1. **uv 설치:** <https://docs.astral.sh/uv/>
2. **키 파일 만들기:** `keys.example.toml`을 `keys.toml`로 복사하고 키를 넣어요.
   - `keys.toml`은 git에 올라가지 않아요. 키를 채팅이나 다른 곳에 붙여 넣지 마세요.

   | 키 | 필수 | 어디서 받나 | 비우면 |
   |---|---|---|---|
   | `[dart] api_key` | 필수 | OpenDART (opendart.fss.or.kr) | 실행 안 됨 |
   | `[krx] auth_key` | 필수 | KRX OPEN API (서비스별 이용 신청 필요) | 실행 안 됨 |
   | `[naver]` | 선택 | NAVER API HUB(네이버 클라우드) 검색 API | 뉴스는 검색 링크만 보여줘요 |
   | `[fisis] auth_key` | 선택 | 금감원 금융통계정보시스템 OPEN API | 금융회사 자본비율이 '직접 확인'으로 나와요 |

3. **계산기 경로 확인:** `settings.toml`의 `[paths] calculator`가 원본 계산기 엑셀을 가리키는지 확인해요. 원본은 읽기만 하고 고치지 않아요.

## 매주 할 일

```
uv run run.py
```

- 상장 주식 전체를 받아 계산하고, 끝나면 리포트를 브라우저로 열어요.
  - 처음에는 1시간쯤 걸려요. 그 뒤로는 받아 둔 자료를 다시 써서 10분 안팎이에요.
- DART 하루 호출 한도에 닿으면 받은 데까지만 리포트를 만들어요. 다음 날 다시 실행하면 이어서 받아요.
- 같은 날 다시 실행하면 그날 리포트를 새로 만들어요.
- 리포트는 `reports/<날짜>/index.html`에 남아요.
- 브라우저를 열지 않으려면 `--no-open`을 붙여요.

## 리포트 보는 법

### 첫 페이지

| 부분 | 보는 법 |
|---|---|
| 맨 위 줄 | 실행 날짜, 몇 일 종가 기준인지, 분석한 종목 수 |
| 숫자 칸 | 매수선 이하 몇 개, 이번 주 새로 들어온 게 몇 개인지 |
| 점수 순위 | 점수 높은 순. 첫 표. 아래 '점수 순위 읽기' |
| 지난주와 달라진 점 | 새로 매수선 아래로 온 종목, 기준이 바뀌어 달라진 종목 |
| 관심 목록 | 매수선에 가까운 순서. 가장 중요한 표예요. |
| 아깝게 탈락 | 기준 한 칸 안쪽 차이로 떨어진 종목 |
| 검색 | 종목명이나 코드로 카드 찾기 |

**점수 순위 읽기**
- **점수 · 등급:** 100점 만점. 80 초과 A · 70 초과 B · 50 초과 C · 나머지 D. 사라는 뜻이 아니라 근거가 얼마나 많은지.
- **싼가 25 · 꾸준히 버나 20 · 배당 지속성 10 · 주주환원 40 · 기타 5:** 묶음별 점수. 항목·구간은 `settings.toml`의 `[score]`.
  - 싼가: PER, PBR, 계산기 주가÷적정가
  - 꾸준히 버나: ROE 5년 평균, 최근 5년 적자 없음, 최근 4분기 실적 유지
  - 배당 지속성: 배당성향이 기준 범위 안, 현금흐름이 배당을 받쳐 줌(금융회사는 자본비율)
  - 주주환원: 배당수익률(정상 DPS 기준이라 특별배당에 안 부풂), 배당 연속 인상, 분기·반기 배당, 자사주 매입·소각, 소각 비율, 자사주 보유 비율
  - 기타: 상장 자회사 없음(중복상장)
- **자료 없는 배점:** DART에 자료가 없어 0점으로 더한 배점. 크면 점수가 실제보다 낮을 수 있음.
- **지난주 대비:** 점수 변화. 배점을 바꾼 주에는 '배점 바뀜'.
- 최근 해에 배당을 안 준 종목은 점수 없음(관문 판정은 그대로 함).
- 표 아래 '계산기 관문 기준'에 원래의 관심 목록과 아깝게 탈락이 있음.

**관심 목록 열 읽기**
- **관문:** 초록은 통과, 노랑은 확인 필요, 빨강은 탈락이에요.
- **주가÷적정가:** 0.75 이하면 매수선 아래예요. 작을수록 싸요.
- **매수선까지:** 매수선까지 얼마나 더 내려야 하는지. 0%면 이미 아래예요.
- **이름 옆 빨간 칩:**
  - **숫자 확인 필요:** 받은 숫자가 이상해 보여요(보고서끼리 다름, 주식 수 급변 등). 카드에서 이유를 봐요.
  - **최근 실적 미달:** 연간 실적으로는 싸지만, 최근 4분기 실적으로 보면 아니에요. 계산기는 연간 숫자만 쓰기 때문에 최대 1년 늦게 반영돼요.

### 종목 카드 (위에서 아래로)

1. **관문 배지:** 노란 배지가 그 종목의 숙제예요.
2. **가격 상자:** 현재가, 보수적 적정가, 매수선이에요. 파란 막대가 빨간 선보다 왼쪽이면 매수선 아래예요.
3. **최근 실적 확인:** '최근 실적 미달'일 때만 나오는 경고예요.
4. **적정가 A·B·C:** 셋 중 가장 낮은 값을 써요.
5. **관문 ①②③ 표:** 항목마다 값, 기준, 결과가 있어요. '입력 필요', '직접 확인'이 숙제예요.
6. **5-4 정상 EPS 가정 표:** 정상 EPS를 바꾸면 매수선이 어떻게 달라지는지 보여줘요.
   - '최근 4분기' 줄은 엑셀에는 없는 참고 줄이에요.
   - 여기서 '싸요'가 여러 줄이어야 튼튼하게 싼 거예요.
7. **5년 입력 숫자와 칸별 출처:** 숫자마다 어느 보고서에서 왔는지 보여줘요.
8. **그래프:** EPS, 배당, 주간 종가
9. **관문 ④ 자료:** 최근 공시, 뉴스, 올해 분기 실적, 세 가지 질문
10. **점수 (가격 상자 바로 아래):** 항목, 이 회사 값, 구간, 점수/배점, 출처. '자료 없음'은 받지 못한 항목.
11. **점수에 없는 판단 (점수 바로 아래):** 이익 지속성·성장 잠재력·경영·브랜드 질문과 평가표 선택지. `/자문`에서 같이 봄.

## 엑셀로 내보내기

```
uv run run.py --excel 004000
```

- 그 종목을 원본 계산기에 채운 사본을 `exports/<날짜>_<종목명>_<코드>.xlsx`로 만들고 열어요.
  - 가장 최근 주간 실행 결과에 그 종목이 있으면 그걸 써요. 없으면 그 종목만 새로 받아요.
  - 원본 계산기와 기존 내보낸 파일은 덮어쓰지 않아요.
- 직접 바꿔 볼 노란 칸:

  | 칸 | 넣을 것 | 결과 |
  |---|---|---|
  | B95 | 정상 EPS 직접 입력 | 적정가·매수선·관문 ③이 다시 계산돼요 |
  | B125 | 내가 생각하는 정상 EPS | 5-4 표에 한 줄만 더해져요 |
  | B129–B133 | 싼 이유 한 문장, 질문 1~3, 나의 판단 | 관문 ④ 결과가 나와요 |

- 엑셀에 쓴 메모는 리포트로 돌아가지 않아요. 둘은 따로 움직여요.

## `/자문`: 관문 ④를 AI와 같이 보기

이 폴더에서 Claude Code를 열고 다음처럼 입력해요.

```
/자문 004000
```

- **진행 순서:**
  1. 리포트 카드를 읽어요.
  2. DART 공식 자료(분기보고서 원문, 공시, 지분 변동, 배당)와 뉴스를 모아요.
  3. 최근 4분기를 확인해요.
  4. 세 질문에 근거를 달아 답 후보를 내요.
  5. 점수에 없는 판단 네 가지(이익 지속성·성장 잠재력·경영·브랜드)에 근거와 답 후보를 달아요. 빠뜨리지 않아요.
  6. B95 시나리오 표, 반대 의견, 다음 확인 일정을 정리해요.
- **메모:** 결과는 `data/memos/<날짜>_<종목명>_<코드>.md`에 남아요. git에는 올라가지 않아요.
  - 같은 종목을 다시 자문하면 지난번과 달라진 점부터 말해 줘요.
- **AI 답을 쓰는 법:**
  - 숫자마다 출처가 붙어 있는지, 카드 숫자와 맞는지 확인하세요.
  - "추측:"으로 시작하는 문장은 확인되지 않은 내용이에요.
  - 사고 안 사고는 직접 정해요.

## 기준 바꾸기

- 기준값은 `settings.toml`에 있어요. 기본값은 엑셀 '기준값' 시트와 같아요.
  - `[criteria]`: 요구수익률, 안전마진, ROE·부채비율 등 관문 기준
  - `[report]`: 관심 목록 범위
  - `[industry.overrides]`: 업종별 기준
  - `[financial]`: 금융회사 자본비율 기준
  - `[score]`: 점수 순위의 배점·구간, 등급 경계, 첫 화면 개수. 숫자만 바꾸면 됨. 바꾸면 다음 리포트 맨 위에 항목별로 표시.
- 기준을 바꾸면 다음 리포트 맨 위에 무엇이 바뀌었는지 표시돼요. 그 변화가 주가 변화처럼 보이지 않게 따로 구분해요.
- 리포트의 '기준 점검' 페이지(`criteria.html`)에서 기준을 한 칸 바꾸면 통과 수와 관심 목록이 어떻게 달라지는지 볼 수 있어요. 판정은 바꾸지 않아요.

## 분석하지 않는 것

- 해외 주식, 외국 회사 주권
- 리츠, 스팩, 우선주, ETF/ETN, 인프라 펀드
- 사업보고서 재무제표가 없는 회사 (리포트의 '실패' 목록에 나와요)
