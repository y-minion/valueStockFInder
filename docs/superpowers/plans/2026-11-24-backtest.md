# 계산기 백테스트 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 2018-04~2026-11 실제 과거 자료로, 계산기가 매수선 이하라고 한 종목을 사용자 규칙대로 매일 사고팔았다면 얼마를 벌었는지 계산해서 비교 페이지로 보여줘요.

**Architecture:**
- 회사×사업연도마다 '판정 묶음(Vintage)'을 미리 계산해요. 계산은 제품의 assemble + evaluate_one을 그대로 쓰고, 그 사업보고서의 원본 공시일 다음 첫 거래일부터 써요.
- 매 거래일 KRX 종가와 묶음을 비교하는 순수 시뮬레이션으로 매매해요. 같은 돈을 ETF·지수에 넣은 비교 기준도 같은 시뮬레이션 틀로 계산해요.
- 결과는 정적 HTML로 써요.

**Tech Stack:** Python 3.13, uv, pytest. 의존성은 httpx·lxml 그대로이고 새 라이브러리는 없어요. 자료는 DART OpenAPI, KRX OPEN API(주식·ETF·KOSPI 시리즈), 금감원 FISIS, 저장소는 data/vsf.sqlite3예요.

**Spec:** `docs/superpowers/specs/2026-11-24-backtest-design.md`

## Global Constraints
- **자료 출처:** 공식 API만 써요(DART, KRX OPEN API, 금감원 FISIS). 실행 중 AI를 쓰지 않아요. 계산기 xlsx는 읽지도 고치지도 않아요.
- **키:** 출력하거나 로그에 남기지 않아요. 로그는 cli.py의 RedactingFormatter 방식으로 지워요.
- **주간 실행은 그대로:** 기존 테스트는 고치지 않고 모두 통과해야 해요. 예외는 Task 2(FakeKrx 메서드 추가)와 Task 4(FakeDart 호출 기록)의 테스트 지원 코드뿐이에요.
- **미래 정보 금지:** 판정 묶음은 그 사업보고서의 원본 공시일 이후 첫 거래일(`valid_from`)부터만 써요.
- **사라진 종목 포함:** 종목 목록은 달마다 첫 거래일의 KRX 종목 목록이에요. 나중에 상장폐지된 종목도 포함해요.
- **결과 위치:** 결과는 `reports/backtest/<실행일>/index.html`, 자료는 `data/`예요. 둘 다 git에서 빠져 있어요(공개 저장소). README.md는 사용자가 고친 내용이 있으니 건드리지 않아요.
- **화면 문구:** 한국어 해요체로 써요.
- **투자 규칙 (스펙 3장의 값 그대로):**
  - 월 입금 1,300,000원, 달마다 첫 거래일
  - 최대 보유 5종목, 한 종목 비중 한도 없음
  - 비용: 살 때와 팔 때 각각 금액의 0.0025. 한 종목 최소 매수 10,000원. 소수점 주식 허용
  - 하루 처리 순서: CMA 이자 → 입금 → 배당 → 팔기 → 사기
  - 팔기: 종가 ≥ 보수적 적정가(B105). 적정가 '계산 불가'면 팔기. 적정가가 없으면 들고 있고 표시
  - 사기: 아직 매수선 이하인 보유 종목 + 빈 자리만큼 주가÷적정가 낮은 순(같으면 코드 순) 새 종목에 CMA 잔액을 똑같이 나눠요. 같은 회사(corp_code)는 한 종목만
- **CMA 대용 ETF:** 214980(KODEX 단기채권PLUS)을 쓰다가, 357870(TIGER CD금리투자KIS(합성))이 처음 시세가 있는 날(2020-07-07)부터 357870을 써요.
- **기간:** 2018-04-01 ~ 2026-11-20. 두 번째 실행은 2020-11-02부터 시작해요.
- **비교 기준:** etf:133690(나스닥100), etf:143850(S&P500 환헤지), index:코스피, etf:161510(고배당). 두 번째 실행에는 etf:360750(S&P500 환노출)을 더해요. 입금과 매수 비용은 같은 규칙이에요.
- **비교 규칙:** "지금 규칙"(settings `[criteria]` 그대로)과 "배당성향 하한 없음"(payout_min 0.0).
- **DART 한도:** 하루 한도는 settings `dart_daily_budget`이고, 주간 실행과 같은 저장소의 호출 기록을 나눠 써요.

1. **주말·휴일에 공시한 사업보고서:** 다음 거래일부터 써요. 기간 끝 뒤에 공시한 보고서는 쓰지 않아요. → Task 7 `test_vintage_starts_on_first_trading_day_after_filing`, `test_vintage_after_period_end_is_not_built`

3. **보유·후보 종목의 분할·무상증자(주식 수 ×r, 주가 ÷r):** 보유 주식은 ×r, 묶음의 적정가·매수선은 ÷r로 맞춰서 가짜 '싸요'나 가짜 손실이 없어야 해요. 유상증자처럼 주가가 따라 움직이지 않으면 맞추지 않아요. → Task 9 `test_split_multiplies_shares_and_scales_fair_value`, `test_rights_offering_is_not_a_split`
4. **같은 회사의 보통주·우선주가 둘 다 쌀 때:** 주가÷적정가가 낮은 하나만 들어요. 하나를 들고 있으면 다른 하나는 사지 않아요. → Task 8 `test_one_share_class_per_company`
5. **자료를 받는 중 DART 하루 한도에 닿을 때:** 깔끔하게 멈추고, 받은 자료는 저장소에 남아요. 다음 실행이 이어 받고, 안내 문구를 보여줘요. → Task 12 `test_quota_stop_says_how_to_resume`
