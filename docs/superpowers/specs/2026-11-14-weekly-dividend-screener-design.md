## 1. 한 줄 요약

지금은 종목마다 숫자를 찾아 엑셀 계산기에 옮겨 적어요. 이 일을 없애는 게 목표예요.

명령어 한 줄로 국내 주식 전체에 그 계산기의 규칙(관문 ①②③)을 적용해요. 그리고 "이번 주에 살 만한 가격으로 내려온 종목"을 브라우저 HTML 리포트로 보여줘요.

## 2. 배경과 이유

**사용자와 계산기**
- 사용자는 ISA 계좌에서 오래 들고 갈 국내 배당주를 골라요.
- 『가속화 장기투자 법칙』의 '배당주 실습 가이드'를 바탕으로 엑셀 계산기를 직접 만들었어요.
- 계산기는 네 관문으로 판정해요.
  - ① 좋은 회사인가
  - ② 배당이 오래 갈까
  - ③ 지금 싼가 (주가 ≤ 매수선)
  - ④ 싼 이유가 일시적인가 (사람이 판단)

**지금 방식의 문제**
- 종목마다 네이버페이 증권, 한경 코리아마켓, DART, ETF쇼핑을 돌아다녀요.
- 숫자 10여 종류를 5~10년 치씩 찾아 노란 칸에 옮겨 적어요.
- 한 종목에 시간이 오래 걸려서 몇 종목밖에 못 봐요.
- 설비투자처럼 찾기 어려운 숫자는 비워 두기도 해요. 예시 시트 두 개 모두 설비투자가 비어서 관문 ②가 '확인 필요'로 나와요.

**이 도구가 주는 것**
- 매수선은 재무 숫자로 정해지는데, 주가는 매일 움직여요.
- 그래서 같은 계산을 매주 전체 시장에 돌리면 좋은 회사가 매수선 아래로 내려오는 순간을 잡을 수 있어요. 이게 이 도구의 핵심 가치예요.
- 사용자는 매주 직접 실행해서 결과를 봐요.
- 후보 종목은 관문 ④를 직접 판단하고, 판단 메모는 엑셀에 써요.

### 5.2 판정 요약

정확한 규칙은 엑셀 수식을 따라요. 아래는 요약이에요.

| 관문 | 항목 | 기준 (기본값) | 비고 |
|---|---|---|---|
| ① | ROE 5년 평균 | 8% 이상 | |
| ① | 부채비율 | 200% 미만 | 가장 최근 해(F열)만 봐요 |
| ① | 이자보상배율 | 3배 이상 | 가장 최근 해만 봐요 |
| ① | 영업현금흐름 합계 ÷ 순이익 합계 (5년) | 1배 이상 | 두 줄의 숫자 개수가 같아야 계산돼요 |
| ② | 배당을 거른 해 (최대 10년) | 0번 | 한 번이라도 있으면 탈락 |
| ② | 배당을 줄인 해 (최대 10년) | 0번 | 1번 이상이면 '직접 확인' (탈락 아님) |
| ② | 평균 배당성향 | 20%~60% | 소수 둘째 자리에서 반올림한 뒤 비교 |
| ② | 잉여현금흐름 합계 ÷ 배당 총액 합계 (5년) | 1배 이상 | |
| ③ | 현재 주가 ≤ 매수선 | 매수선 = 보수적 적정가 × (1 − 25%) | |

**관문 결과를 정하는 순서**
1. '탈락'이 하나라도 있으면 탈락이에요.
2. 없으면, '입력 필요'가 있을 때 '확인 필요'예요. 관문 ②는 '직접 확인'도 '확인 필요'로 봐요.
3. 둘 다 없으면 통과예요.

**적정가 계산**
- 정상 EPS = 최근 5년 EPS 평균
- 정상 DPS = 정상 EPS × 평균 배당성향
- 적정가 A (이론) = 정상 EPS ÷ 요구수익률
- 적정가 B (과거 PER) = 정상 EPS × 정상인 해 평균 PER
- 적정가 C (과거 배당수익률) = 정상 DPS ÷ 평균 배당수익률
- 보수적 적정가 = A, B, C 중 가장 낮은 값

### 5.3 놓치기 쉬운 규칙

- **0과 빈칸은 달라요.**
  - DPS 0 = 배당을 안 줬다는 뜻이에요. 관문 ② 탈락 사유가 돼요.
  - 빈칸 = 자료가 없다는 뜻이에요. 계산에서 빠져요.
  - 프로그램도 "값 없음"과 "0"을 구분해서 저장해요.
- **'비정상인 해'는 EPS ≤ 0이거나 EPS < 정상 EPS × 0.5인 해예요.**
  - 평균 PER, 평균 배당수익률, 평균 배당성향에서만 빠져요.
  - 정상 EPS 평균에는 그대로 들어가요.
- **평균은 빈칸을 건너뛰어요.** 엑셀의 AVERAGE, AVERAGEIFS와 같은 방식이에요. 값이 하나도 없으면 결과도 빈칸이에요.
- **배당수익률은 연말 주가를 거꾸로 계산해서 내요.** 연말 주가 = 연말 PER × EPS이고, EPS > 0일 때만 계산해요.
- **첫해(B열)의 배당 증감률은 1-1번의 마지막 해(F42)와 비교해요.**
- **정상 EPS ≤ 0이면** 보수적 적정가는 '계산 불가', 관문 ③은 탈락이에요.
- **'적정가를 정한 방법'은 이 순서로 정해요.** A와 같으면 A, 아니면 B와 같으면 B, 아니면 C.
- **사람이 판단해서 넣는 칸은 프로그램이 비워 둬요.** 사용자는 엑셀에서 직접 넣어요.
  - 평균에서 뺄 해 (37행 X)
  - 배당 계산에서만 뺄 해 (38행 X)
  - 정상 EPS 직접 입력 (B95)
- **5-3번과 5-4번은 판정에 안 쓰지만 상세 카드에 그대로 보여줘요.** 5-3번은 '시장이 예상하는 것', 5-4번은 'EPS 가정을 바꾸면'이에요.

- 처음엔 참고 숫자로만 보면서 감을 잡아요.
- 업종별 기준은 그다음에 정해요.

**무엇을 보여주나**
- 첫 페이지와 상세 카드: 업종 안에서 ROE 5년 평균 순위(상위 몇 %)와 업종 중간값.
- 상세 카드에는 부채비율 순위와 중간값도 함께 보여줘요. 업종마다 차이가 큰 항목이라서요.

**업종 분류**
- DART 기업개황의 업종코드(한국표준산업분류, KSIC)를 써요.
- 사람이 읽을 수 있는 업종 이름으로 묶어요.
- 한 묶음에 회사가 너무 적으면(예: 5개 미만) 한 단계 위 분류로 묶어요. 정확한 단계는 빌더가 정해요.
- 대화에서 사용자에게는 "KRX 업종 분류"를 쓴다고 했어요. 그런데 KRX 데이터 사이트가 2026년 들어 로그인을 요구한다는 보고가 여럿 있어서 DART 업종코드로 바꿨어요.

**업종 비교를 판정에 넣으면**
- 관문 ①에 '업종 안 ROE 순위' 항목이 하나 추가돼요.
- 업종별 기준 덮어쓰기가 있으면, 그 업종 종목은 덮어쓴 숫자로 판정해요.
- 리포트에 종목마다 어떤 기준이 적용됐는지 보여줘요.

### 6.3 대상 종목

**제외**
- 금융회사: 은행, 보험, 증권, 카드, 캐피탈, 금융지주.

**제외한 종목 보여주기**

### 6.4 갱신과 호출 한도

**무엇을 언제 새로 받나**
- 재무 숫자는 저장해 둬요.
- 새 사업보고서나 정정 보고서가 나온 회사만 다시 받아요. DART 공시검색으로 확인해요.
- 주가는 실행할 때마다 새로 받아요.
- 과거 연말 종가는 한 번 받으면 바뀌지 않으니 저장해 둬요.
- 매년 3~4월에는 회사마다 최근 연도가 다를 수 있어요. 새 사업보고서가 나온 회사부터 바뀌기 때문이에요. 그래서 종목마다 최근 연도를 표시해요.

**첫 실행**
- 추정 호출 수: 종목당 DART 6~8번 × 약 2,500종목. 하루 한도와 비슷해서 하루를 넘길 수 있어요.
- 한도에 닿으면 멈추고, 다음 실행 때 이어서 받아요.
- 그때까지 받은 종목으로만 리포트를 만들고, "전체 N개 중 n개 분석"을 크게 표시해요.
- 배당을 한 번도 안 준 회사는 관문 ②에서 어차피 탈락이에요. 배당 자료부터 받아서 재무제표 호출을 줄여도 돼요 (빌더 판단).

**매주 실행**
- 몇 분 안에 끝나는 게 목표예요.

### 6.5 알려진 함정

**액면분할·무상증자**
- 사업보고서의 비교 연도 EPS는 보통 새 주식 수 기준으로 다시 계산돼서 나와요.
- 하지만 오래된 보고서의 숫자는 옛 주식 수 기준이에요.
- 겹치는 해의 EPS 비율로 조정 배수를 찾을 수 있어요.
- PER과 배당수익률은 같은 기준끼리 계산해야 해요. 그해 보고서의 EPS와 수정하지 않은 종가를 짝지어요.

**이자비용이 손익계산서에 없을 때**
- 현금흐름표의 '이자의 지급'을 대신 쓸지, OpenDART 주요 재무지표 API에 있는지는 빌더가 판단해요.
- 무엇을 썼는지 출처에 남겨요.
- 차입금이 없어서 이자비용이 0이면 엑셀 규칙대로 999를 넣어요.

**계정 이름이 회사마다 달라요**
- XBRL 표준 계정 ID로 먼저 찾아요.
- 이름으로 찾은 경우에는 그렇게 표시해요.

**단위**
- DART 금액은 원 단위예요. 계산기는 억 원이라 바꿔야 해요.
- 통화가 원이 아니면 표시해요.

**정정 공시**
- 같은 해 보고서가 정정되면 가장 최근 것을 써요.

**특별배당**
- 배당성향이 100%를 넘는 해에는 "특별배당 의심" 메모를 달아요.
- 판정은 바꾸지 않아요. 엑셀에서는 사용자가 X로 빼요.

### 6.6 숫자 신뢰

**출처 기록**
- 칸마다 출처를 저장해요: 어느 보고서인지, 접수번호, 계정.
- 상세 카드에서 볼 수 있어요.

**자동 검사**
- 검사 예:
  - 겹치는 해의 숫자가 두 보고서에서 다름
  - EPS와 순이익의 부호가 다름
  - PER이 터무니없이 큼
- 걸리면 '숫자 확인 필요' 표시를 달아요.
- 종목을 숨기지는 않아요. 첫 페이지 목록과 상세 카드에 표시가 보여요.

**못 가져온 숫자**
- 빈칸으로 둬요. 그러면 엑셀 규칙대로 '입력 필요'나 '확인 필요'가 돼요.
- **절대 0으로 채우지 않아요.**

## 7. 리포트

### 7.1 형태

- 정적 HTML이에요. 서버 없이 파일로 열려요.
- 실행이 끝나면 브라우저로 자동으로 열어요.
- 모든 글은 한국어예요.
- 실행마다 날짜 폴더에 보관해요(예: `reports/2026-11-14/`). 지난 리포트를 다시 열 수 있어요.
- 디자인 시안은 사용자가 대화 중에 골랐어요.
  - A(이번 주 변화 중심)를 첫 페이지로
  - C(후보 종목 카드)를 종목별 상세로
  - 시안 파일: `.superpowers/brainstorm/9140-1794632385/content/report-layout.html`

### 7.2 첫 페이지

**머리**
- 실행 날짜, 주가 기준일
- 분석한 종목 수 / 전체 / 제외
- 적용한 기준 요약
- 기준이 바뀌었으면 변경 알림

**요약 숫자** (지난주 숫자와 함께)
- 매수선 이하 (③ 통과)
- 매수선까지 10% 이내
- 관심 목록 (20% 이내)
- ①② 탈락 아님

**이번 주 변화 표**
- 종류: 새로 매수선 이하 / 새로 관심 목록 / 빠짐
- 변화마다 원인을 표시해요: 주가 / 재무 갱신(새 사업보고서) / 기준 변경

**관심 목록 표**
- 조건: ①② 탈락이 아니고, 매수선까지 20% 이내.
- 정렬: 주가 ÷ 적정가가 낮은 순.
- 열:
  - 종목 (업종)
  - ①②③ 배지
  - 주가 ÷ 적정가
  - 매수선까지 %
  - 현재 배당수익률
  - 적정가를 정한 방법
  - 업종 안 ROE 순위 (참고)
  - '숫자 확인 필요' 표시

**종목 검색 (Claude 결정)**
- 분석한 모든 종목을 이름이나 코드로 찾아서 상세 카드를 열 수 있어요.

### 7.3 종목 상세 카드

**판정 요약**
- 관문 ①②③ 배지 + ④는 "직접 판단 필요"
- 현재가 / 보수적 적정가(정한 방법) / 매수선
- 주가 ÷ 적정가 막대
- '다음에 할 일' 문장

**엑셀과 같은 내용**
- 적정가 A, B, C 세 값
- 관문 ①·② 항목표 (이 회사 값 / 기준 / 판정). 엑셀 3·4번과 같은 모양이에요.
- 5-1번 평균값
- 5-3번 시장이 예상하는 것
- 5-4번 EPS 가정을 바꾸면

**입력 숫자와 그래프**
- 5년 입력 숫자 표 + 그 이전 5년 DPS. 칸마다 출처가 보여요.
- EPS 막대 + 정상 EPS 점선 그래프 (엑셀 그래프와 같은 뜻)
- 10년 DPS 그래프

**업종 비교 (참고)**
- 업종 이름
- 업종 ROE 중간값과 이 회사 순위
- 업종 부채비율 중간값과 이 회사 순위

**관문 ④ 판단 자료 (관심 목록 종목만, Claude 결정)**
- 최근 DART 공시 목록
- 뉴스 제목
  - 네이버 검색 API 키(무료, 따로 발급)를 넣으면 제목을 가져와요.
  - 키가 없으면 뉴스 검색 링크만 달아요.
- 올해 분기 누적 실적 vs 작년 같은 기간 (참고용, 판정에 안 씀)
- 최근 1년 주가 흐름
- 엑셀 6번의 세 질문과 참고 문구 (C131, C132와 같은 내용)

**엑셀 만들기 안내**
- `--excel 종목코드` 명령을 보여줘요.

### 7.4 이번 주 변화의 원인 구분

- 실행할 때마다 입력(주가, 재무 숫자)과 설정을 저장해요.
- 원인 표시는 필수예요. 원인을 가르는 방법은 빌더가 정해요.
- 제안하는 방법:
  1. 지난 입력에 새 설정을 넣어 다시 계산하면 기준 변경 효과가 나와요.
  2. 그다음 새 주가로 바꿔서 계산해요.
  3. 마지막으로 새 재무 숫자로 바꿔서 계산해요.
  4. 어느 단계에서 결과가 바뀌었는지 보면 원인을 알 수 있어요.
- 첫 실행은 "비교할 지난 결과 없음"으로 표시해요.

- 다른 프로그램을 설치하지 않아요. 만들기와 확인도 설치 없이 해요.
- 애플 호환성 표 기준으로, 계산기를 Numbers로 열면 이렇게 돼요.
  - 지원해요: AVERAGEIFS, COUNTIF, COUNTBLANK, IFERROR, INDIRECT, ISNUMBER, ROUND, LEN, MIN, MAX. 그래서 판정 칸(관문 결과, 적정가, 매수선, 관문 ④ 결과)은 Numbers에서도 다시 계산돼요.
  - 조건부 서식(색 표시)도 지원해요.
  - **TEXT 함수는 지원하지 않아요.** 기준 글자("≥ 8%"), '다음에 할 일'(B15), C11·C13·C14, C131·C132 같은 문장 칸이 TEXT를 써요. 이 칸들은 파일에 저장된 값으로 고정되고, 입력을 바꿔도 안 바뀌어요. 사용자는 이걸 받아들였어요.
  - **데이터 유효성 검사(목록 고르기)는 지원하지 않아요.** 37·38행 X와 ④ 칸은 직접 입력해야 해요. 사용자는 이것도 받아들였어요.
  - 막대+선 혼합 그래프는 표에 따로 나와 있지 않아요. 막대와 선은 각각 지원돼요.

**파일 만들기**
- 원본 계산기를 복사해서 새 파일을 만들어요. 원본은 읽기만 해요.
- 파일 위치와 이름 (Claude 결정): 프로젝트 안 한 폴더에 `날짜_종목명_종목코드.xlsx`로.
- 같은 이름의 파일이 있으면 **절대 덮어쓰지 않아요.**

**채우는 칸** (`분석_빈칸` 시트의 노란 칸)
- 0번: 종목명, 종목코드, 현재 주가, 주가 기준일, PBR, 자료 출처 메모(B23)
- 1번: 26–36행
- 1-1번: 41–42행
- 비워 두는 칸: 37·38행, B95, 6번, 7번
- 채운 시트 이름은 종목명으로 바꿔요 (Claude 결정, 엑셀 사용법 1번과 같은 방식).

**B23 메모에 적는 것**
- 자동 수집한 출처와 날짜
- '숫자 확인 필요' 항목
- Numbers용 입력 안내: ④ 질문 칸에는 '예', '아니오', '모르겠음' 중 하나를, 나의 판단 칸에는 '일시적', '구조적', '모르겠음' 중 하나를 글자 그대로 입력해요. 관문 ④ 결과 수식이 이 글자와 정확히 같은지로 판정하기 때문이에요.

**기준값 시트 맞추기**
- `기준값` 시트를 그 종목에 실제로 적용된 기준으로 바꿔요 (설정 + 업종 덮어쓰기).
- 그래야 엑셀 판정과 리포트 판정이 같아요.
- 업종 비교 항목처럼 엑셀에 없는 판정은 B23 메모에 적어요.

**Numbers에서 보여야 하는 것**
- 숫자, 판정, 적정가, 매수선, 문장 칸이 그날 리포트와 같은 값으로 보여야 해요.
- 사용자가 ④ 칸을 입력하거나 숫자를 고치면, 판정 칸은 다시 계산돼야 해요.
- 색 표시와 EPS 그래프가 보여야 해요.
  - 혼합 그래프가 Numbers에서 깨지면 대안은 빌더가 판단해요 (예: 막대 그래프만).
  - 그래프는 리포트 상세 카드에도 있으니, 엑셀 쪽 그래프는 '있으면 좋은 것'이에요.

**구현할 때 주의할 점**
- **모든 수식 칸에 프로그램이 계산한 결과값도 함께 저장해요.**
  - Numbers는 지원하지 않는 수식(TEXT 등)을 만나면 파일에 저장된 마지막 계산값을 보여줘요.
  - 결과값이 비어 있거나 틀리면 그 칸이 빈칸이나 틀린 값으로 보여요.
  - 엑셀이나 LibreOffice로 열 때를 위해 `fullCalcOnLoad=1`(열 때 다시 계산) 설정도 유지해요.
- **그래프는 시트 이름을 직접 가리켜요** (`'분석_빈칸'!$B$27:$F$27` 등). 시트 이름을 바꾸면 그래프 참조도 같이 고쳐야 해요.
- **흔히 쓰는 파이썬 엑셀 라이브러리(openpyxl)는 파일을 불러왔다가 저장하면 기존 그래프를 지워요.**
- **종목코드 칸(B19)은 글자로 저장해요.** 앞자리 0이 사라지면 안 돼요.

**결과 확인**
- 이 맥의 Numbers로 파일을 자동으로 열어서 칸 값을 읽고, 그날 리포트의 그 종목 값과 비교해요. 방법은 빌더가 정해요 (예: AppleScript).
- 마지막으로 사용자가 Numbers에서 한 번 눈으로 확인해요.

## 10. 완료 기준

1. **계산 일치**
   - 정답은 계산기 파일의 실제 수식을 엑셀 수식 계산 도구로 계산한 값이에요 (5.1 참고). 파일에 저장된 값이 아니에요.
   - 아래 입력들로 프로그램 결과와 정답을 비교해요.
     - `예시_제일기획`, `예시_기아`, `분석_빈칸`(빈 입력)
     - 일부러 만든 경우들:
       - 정상 EPS ≤ 0
       - 비정상인 해가 있는 경우
       - 37·38행 X 표시
       - DPS가 0인 해
       - 이자보상배율 999
       - 5년 순이익 합계가 0 이하
       - 숫자 개수가 안 맞는 경우 (영업현금흐름 vs 순이익, 설비투자 vs 영업현금흐름)
       - 일부 해가 비어 있는 경우
       - 정상 EPS 직접 입력(B95)
   - 모든 계산 칸이 판정 문구까지 같아야 해요. 숫자는 소수점 오차 수준까지 같아야 해요.
   - 파일에 저장된 값과도 비교해 보고, 다르면 어느 쪽이 맞는지 적어요.
2. **데이터 확인**
   - 제일기획(030000)과 기아(000270)의 2021–2025 숫자를 자동으로 가져와요.
   - 예시 시트에 손으로 넣은 숫자와 칸별로 비교한 표를 만들어요.
   - 출처가 달라서 생기는 차이는 이유를 적어요. 예: 한경 vs DART, 기아 영업현금흐름은 조 원 단위로 반올림해서 넣었음.
   - 설명되지 않는 5% 넘는 차이는 고쳐요.
   - 판정(①②③, 적정가 방법)은 같아야 하고, 적정가는 몇 % 안으로 맞아야 해요.
   - 판정이 다르다면, 새로 채워진 숫자(설비투자 등) 때문인지 설명해요.
3. **엑셀 내보내기 (Numbers 기준)**
   - 기아로 파일을 만들어 이 맥의 Numbers로 자동으로 열어요.
   - 숫자, 판정, 적정가, 매수선, 문장 칸이 그날 리포트와 같아야 해요.
   - ④ 칸에 '예', '일시적' 등을 입력하면 관문 ④ 결과 칸이 다시 계산돼야 해요.

   - 원본 파일이 바뀌지 않았는지 수정 시각과 해시로 확인해요.
   - 마지막으로 사용자가 Numbers에서 한 번 눈으로 확인해요.
4. **전체 실행**
   - 전체 시장 실행이 끝까지 돌고 리포트가 열려요.
   - 제외 종목 수와 실패 종목 수가 보여요.
